## 🎯 The Problem We Solve

<div align="center">

```
┌─────────────────────┐          ❌ No bridge          ┌─────────────────────┐
│                     │  ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ──  ▶ │                     │

│  Accountants (CA)   │  Siloed teams. Duplicated       │  Teams (DS)         │

│  Regulatory Rules   │                                 │  Data Pipelines     │

```

</div>

Modern enterprises operate across two fundamentally different knowledge domains: **financial intelligence** (handled by Chartered Accountants) and **data-driven insight generation** (handled by Data Scientists). Despite working toward the same organizational goals, these teams are **structurally siloed** — leading to:

- 🔴 **Duplicated effort** across financial and analytical workflows
- 🔴 **Miscommunicated findings** between technical and financial domains
- 🔴 **Delayed executive decision-making** due to incompatible reporting formats
- 🔴 **Regulatory non-compliance risk** from missed constraint violations

> There is currently **no dedicated platform** that bridges this interdisciplinary gap. Firms rely on generic project management tools, spreadsheets, and email threads — none designed for financial-analytical collaboration at scale.

---

## 🌐 What is CADS-Bridge?

**CADS-Bridge** (Collaborative Analytics & Decision Support Platform) is a **purpose-built, enterprise-grade web application** that gives Chartered Accountant and Data Science teams a **unified collaborative workspace** — enabling them to:

- 📊 Share data, KPIs, and analytical outputs in domain-appropriate formats
- 🤝 Co-author analytical pipelines with full regulatory context
- 🔒 Operate within **fully isolated, firm-specific environments**
- 📋 Produce board-ready, executive-level stakeholder reports
- ⚡ Detect and resolve CA-DS data conflicts **automatically**

CADS-Bridge is **not** a replacement for your ERP or ML infrastructure — it is the **intelligence layer that connects them**.

## 🚀 Core Platform Features

<details>
<summary><b>🏢 1. Isolated Firm-Specific Environments</b></summary>

Each organization receives **fully isolated, dedicated infrastructure** with:
- Complete data separation and zero cross-contamination between firms
- Multi-team structures with CA and DS segregation within the same environment
- Customizable role-based access control (RBAC) with firm-specific configuration
- Independent admin controls, audit trails, and performance monitoring
- Scalable multi-tenant deployment architecture

</details>

<details>
<summary><b>📁 2. Collaborative Project Creation & Management</b></summary>

Guided project setup with **structured cross-functional workflow**:
- Step-by-step project initialization: details → team selection → timeline → feature scoping → admin approval
- Clear ownership chains and accountability from day one
- Full history tracking of all project creation, modifications, and team assignments
- Dependency mapping and sub-task support across CA and DS workstreams

</details>

<details>
<summary><b>📈 3. Unified KPI Command Centre</b></summary>

A **customizable, role-aware dashboard** that aggregates:
- Financial KPIs managed by CA teams (P&L, variance, compliance metrics)
- Model-driven metrics managed by DS teams (prediction accuracy, data drift, pipeline health)
- Shared cross-domain KPI insights for executive decision-making
- Data-driven performance tracking with individual and team-level visibility

</details>

<details>
<summary><b>🔍 4. Audit Trails & Task Management System</b></summary>

**Jira-class audit logging** with complete version control:
- Every data model or analytical output logged with creator, timestamp, and full modification history
- Task assignment and tracking with status updates, dependency mapping, and accountability chains
- Regulatory constraint breach logs and model evolution change logs
- Immutable audit records suitable for regulatory submission and board review

</details>

<details>
<summary><b>✏️ 5. Collaborative Annotation & Markup Engine</b></summary>

**Context-aware annotation workspace** for bidirectional knowledge transfer:
- CA teams annotate DS model outputs with financial constraints and regulatory context
- DS teams annotate financial data with data quality observations and pipeline notes
- Inline comments, version-tracked markup, and collaborative refinement threads
- Annotated outputs serve as **living documentation** of decision rationale

</details>

<details>
<summary><b>📚 6. Cross-Domain Knowledge Hub</b></summary>

A **living repository** of firm-specific domain intelligence:
- Searchable glossary mapping CA financial terminology ↔ DS technical equivalents
- Historical project deliverables, best-practice guidelines, and collaborative documentation
- Category filtering by department (Finance, Analytics, Operations)
- Accelerates new team member onboarding and reduces cross-domain communication friction

</details>

<details>
<summary><b>⚠️ 7. Conflict Detection & Resolution Suite</b></summary>

**Automated discrepancy detection engine** that:
- Compares DS-generated revenue/cost projections against CA-reported actuals
- Flags divergences exceeding the 5% threshold automatically
- Detects regulatory constraint violations before implementation
- Provides structured conflict resolution workflow with root-cause analysis and reconciliation tracking

</details>

<details>
<summary><b>🤝 8. Shared Collaborative Project Workspace</b></summary>

**Real-time collaboration environment** with:
- Simultaneous multi-user editing and co-authoring
- Integrated messaging, file uploads, task assignment, and status tracking
- Full audit history of all contributions with clear ownership
- Cross-functional brainstorming and joint decision-making infrastructure

</details>

<details>
<summary><b>📊 9. Stakeholder Reporting & Presentation Engine</b></summary>

**Executive-grade report generation** combining:
- Financial narratives (CA perspective) + model insights (DS perspective) in one coherent output
- Automated report generation from shared live data
- Version control for presentations with approval workflow
- Outputs suitable for board presentations, investor briefings, and regulatory submissions
- Export to PDF/Excel with scheduled delivery and drill-down dashboards

</details>

<details>
<summary><b>🌉 10. Domain Glossary & Terminology Bridge</b></summary>

**Firm-specific jargon translation layer** with:
- Context-aware definitions with real-project usage examples
- Bidirectional mapping: CA financial terms ↔ DS data science equivalents
- Search functionality with category filtering
- Accessible platform-wide to reduce miscommunication at every interaction

</details>

## 🚦 Getting Started

### Prerequisites

```bash
Node.js >= 18.x
npm >= 9.x
Azure SQL Server instance (or Azure free tier account)
Cloudinary account (free tier available)
```

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/HassanNawaz14/CADS-Bridge.git
cd CADS-Bridge

# 2. Install all dependencies (root + client + server) in one command
npm run install:all
```

### Environment Configuration

```bash
# Navigate to server directory and create .env
cd server
cp .env.example .env
```

Configure your `.env`:
```env
PORT=5000
AZURE_SQL_SERVER=your-server.database.windows.net
AZURE_SQL_DATABASE=cads-bridge
AZURE_SQL_USER=your_db_user
AZURE_SQL_PASSWORD=your_db_password
CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_api_key
CLOUDINARY_API_SECRET=your_api_secret
JWT_SECRET=your_super_secure_jwt_secret
CLIENT_URL=http://localhost:3000
NODE_ENV=development
```

### Running the Application

```bash
# From root directory — runs client & server concurrently
npm run dev

# Or run independently:
npm run server    # Express API on :5000
npm run client    # React app on :3000
```

### Access Points

| Service | URL |
|:---|:---|
| React Frontend | `http://localhost:3000` |
| Express API | `http://localhost:5000` |
| API Health Check | `http://localhost:5000/api/health` |
